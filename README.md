# Agentic Open-Source Engineering Methodology

> A practical, evolving methodology for designing, developing, verifying, maintaining, and evolving open-source software with AI agents.

[简体中文](README.zh-CN.md)

This repository is currently in **private incubation**. Its purpose is to develop a concise and practical engineering decision system for human–agent collaboration in open-source projects.

The methodology is built around one meta-principle:

> **Outcomes over Dogma.** Principles guide engineering judgment; they do not replace it.

The initial v0.1 structure and documentation are being prepared.
