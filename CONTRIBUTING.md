# Contributing

Thank you for considering a contribution to **Agentic Engineering Preferences**.

This repository is intentionally a public personal engineering reference. Contributions are welcome, but the goal is not to form community consensus about universal best practices.

## What Makes a Good Contribution

A useful contribution normally does at least one of the following:

- clarifies a recurring engineering preference or decision rule;
- improves the evidence or reasoning behind an existing preference;
- makes the reference easier for humans or coding agents to use;
- removes ambiguity, duplication, or unnecessary process;
- identifies a preference that belongs in project-local instructions rather than this repository.

Before proposing a new rule, ask:

1. Does this reflect a recurring engineering need?
2. Does it reduce repeated decisions or repeated agent explanation?
3. Does it belong in this cross-project personal reference rather than one specific project?

A different engineering style being reasonable is not, by itself, a reason to replace the maintainer's documented preference.

## Contribution Expectations

- Keep changes focused and reviewable.
- Prefer concrete engineering consequences over abstract terminology.
- Do not add rules for taxonomy completeness, trend coverage, or symmetry.
- Keep project-local context authoritative over generic preferences.
- Do not introduce private data, secrets, machine-specific paths, or unpublished material.
- Avoid unnecessary dependencies, automation, generated artifacts, and process overhead.
- Update both README language entry points when product identity or first-use behavior changes.

## Pull Requests

A pull request should explain the problem, proposed change, why it belongs here, and how it was validated.

## Language

English is the default operational language for core reference documents. The README is maintained in English and Simplified Chinese as the primary bilingual entry point.

Additional translations should be added only when they materially improve use.
